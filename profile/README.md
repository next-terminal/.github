## Overview

Next Terminal is a bastion host for enterprise operations. It centralizes asset and authorization management, records and replays sessions, and supports auditing and compliance. Designed for teams that need controlled remote access for RDP, SSH, VNC, Telnet, and HTTP.

> Note: Backend has been closed-source since v2.0.0. Frontend and documentation remain open. See [LICENSE](https://github.com/next-terminal/next-terminal/blob/master/LICENSE) before use.

## Key Features

- **Multi-protocol access**: RDP, SSH, VNC, Telnet, HTTP (via Guacamole and gateways)
- **Session auditing**: recording, replay, offline logs, linked to operation logs and grants
- **Assets & authorization**: grouping, user/role grants, gateways and access policies
- **Security gateway**: split access / security gateways for distributed and private networks
- **Enterprise features**: organization management, session sharing, file management, scheduled tasks, certificates
