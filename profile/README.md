## 简介

Next Terminal 是一个面向企业运维场景的堡垒机 / 运维审计系统。它通过统一入口管理资产与授权，记录并回放会话，协助安全审计与合规追溯。适用于需要集中管控远程访问的中小型团队与企业内网。

> 提示：自 v2.0.0 起后端代码不再开源。前端与文档持续开放，商业授权详见 [LICENSE](https://github.com/next-terminal/next-terminal/blob/master/LICENSE)。

## 核心能力

- **多协议接入**：RDP、SSH、VNC、Telnet、HTTP（通过 Guacamole 等网关）
- **会话审计**：录制、回放、离线日志，关联操作日志与授权关系
- **资产与授权**：资产分组、用户/角色授权、网关与接入策略
- **安全网关**：接入网关 / 安全网关分离部署，支持分布式与内网穿透
- **企业特性**：组织管理、会话分享、文件管理、计划任务、证书与配置
