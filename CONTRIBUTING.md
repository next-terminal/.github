# Contributing

Thank you for your interest in Next Terminal.

- **Before filing an issue**: search existing Issues/Discussions to avoid duplicates.
- **Feature requests**: describe the use case, current pain, and expected behavior; include screenshots or recordings if helpful.
- **Bug reports**: include version, deployment method, reproduction steps, logs, and expected vs actual behavior.
- **Docs**: see [`next-terminal/document`](https://github.com/next-terminal/document).

> Note: Backend has been closed-source since v2.0.0. This repo hosts organization profile and default community health files. Code contributions follow the guide in `next-terminal/next-terminal`.
